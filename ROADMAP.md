# Claude Skills Atlas Roadmap

The Atlas is intended to grow into a large, searchable community library of reusable Claude resources.

## Phase 1 — Foundation
- [x] Repository structure
- [x] Contribution guidelines
- [x] Code of Conduct
- [x] Security policy
- [x] Skill and prompt templates
- [x] Initial curated skills and prompts
- [x] Community source catalog
- [x] Polished README

## Phase 2 — Discoverability
- [ ] Build a searchable master catalog
- [ ] Add domain, difficulty, and use-case metadata
- [ ] Add installation/copy instructions
- [ ] Add contribution labels and starter issues
- [ ] Add validation checks for resource structure
- [ ] Add a machine-readable catalog (JSON)

## Phase 3 — Community
- [ ] Reach 100+ high-quality resources
- [ ] Add contributors from multiple disciplines
- [ ] Establish recurring community contribution drives
- [ ] Highlight notable community contributions
- [ ] Create domain maintainers as the project grows

## Phase 4 — Tooling
- [ ] Automatic SKILL.md validation
- [ ] Markdown/link checks
- [ ] Duplicate-content detection
- [ ] Catalog generation from repository files
- [ ] Optional static website for browsing and copying resources

## Contribution principle

Quality comes before quantity. The goal is not to manufacture activity or copy large prompt collections. The goal is to build a genuinely useful, well-attributed library that people return to and contribute to.
