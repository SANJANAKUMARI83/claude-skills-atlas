# Skill Submission Template

Use this template for a new reusable skill.

## Name

Describe the skill in one line.

## Purpose

What task does it solve?

## When to use

When should a user activate this skill?

## Instructions

Write the actual instructions Claude should follow.

## Inputs

List the information the user or workflow needs to provide.

## Outputs

Describe the expected output.

## Example

Show one realistic example.

## Limitations

State important limitations, assumptions, or cases where validation is still required.
