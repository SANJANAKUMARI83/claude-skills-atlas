# Claude Skills Atlas Plugin

The official Claude Code plugin for the public Claude Skills Atlas library.

## Install

```text
/plugin marketplace add cellrishi-code/claude-skills-atlas
/plugin install claude-skills-atlas@claude-skills-atlas
```

## Local development

```bash
claude --plugin-dir ./plugins/atlas
```

## Portable use

The repository is intentionally not locked to Claude Code. Copy any complete `SKILL.md` into an agent's skills directory, or copy any prompt from `prompts/` into your agent workflow.

See `INSTALL.md` at the repository root.
