# Support

If you need help using or contributing to Claude Skills Atlas:

## Questions about using a resource

Open a GitHub issue with the `question` label and include:
- The resource path
- What you were trying to do
- The behavior you expected
- The behavior you observed

## Suggesting a new resource

Open an issue before starting larger additions. Explain:
- The problem the resource solves
- The intended audience
- The proposed resource type
- A short example of the expected workflow

## Contribution help

Read [CONTRIBUTING.md](CONTRIBUTING.md) first. For beginner-friendly work, look for issues labeled `good first issue` or `help wanted`.

## Security

Do not report security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
