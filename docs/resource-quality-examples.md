# Resource Quality Examples

## Prompt

Weak: `Help me debug my code.`

Reusable:

```text
Debug this {{language}} program. Identify the first definite failure, explain its cause, give the smallest correction, and provide one verification step. Do not rewrite unrelated code.
```

The second version defines inputs, behavior, scope, and output.

## Skill

Weak skills give only a goal. A strong skill defines when to activate, a repeatable procedure, expected outputs, and limitations.

## Workflow

A weak workflow says “research the topic.” A strong workflow defines search, evidence extraction, comparison, uncertainty handling, and final verification.

## Agent

A weak agent is just a persona. A strong agent has a focused role, explicit responsibilities, boundaries, tools it may use, and a verification loop.

All examples here are original and intentionally short.
