# Claude Skills Atlas — हिंदी

Claude Skills Atlas AI agents के लिए reusable skills, prompts, workflows और templates की सार्वजनिक लाइब्रेरी है।

शुरू करने के लिए:

1. `INSTALL.md` देखें।
2. `skills/` में अपनी जरूरत का skill चुनें।
3. एक बार के काम के लिए `prompts/` देखें।
4. योगदान देने के लिए `docs/contributor-onboarding.md` पढ़ें।

अंग्रेज़ी दस्तावेज़ मूल स्रोत हैं; यह अनुवाद उन्हें समझने में सहायता के लिए है।
