# Community Research Notes

This document records public sources consulted while expanding the Atlas. The project uses these sources for discovery and pattern analysis; it does not copy their prompt or skill files wholesale.

## Sources reviewed

- Anthropic's public Agent Skills repository demonstrates self-contained skills with metadata, instructions, examples, and supporting resources: https://github.com/anthropics/skills
- Claude Code documentation emphasizes precise activation descriptions, project-level sharing, optional supporting files, and focused skill files: https://code.claude.com/docs/en/skills
- The-Kinetic-Team/claude-skills collects community examples spanning development, testing, design, and enterprise workflows.
- alexknowshtml/claude-skills highlights reusable workflows such as implementation/review, session reflection, skill creation, and teaching.
- slavins-co/claude-skills demonstrates implementation/review, shipping, planning, and learning-oriented skills.
- Reddit discussions in r/ClaudeAI repeatedly point to GitHub, Reddit, and X as discovery channels and show demand for practical, reusable workflows.

## Curation approach

The Atlas converts useful public patterns into original resources rather than copying large third-party collections.

When a source is reused directly, contributors must check its license and preserve required attribution. Community discussions are treated as signals for useful problems, not as automatically redistributable content.

## Themes identified

1. Repository understanding before implementation
2. Structured implementation and review loops
3. Evidence-first research
4. Source and claim verification
5. Session reflection and skill extraction
6. Clear skill activation descriptions
7. Small, testable reusable workflows
