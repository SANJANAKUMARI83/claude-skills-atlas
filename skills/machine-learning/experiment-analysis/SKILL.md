# ML Experiment Analysis

Record dataset/version, preprocessing, seed, model configuration, training procedure, metrics, and evaluation split.

Compare experiments on the same evaluation protocol. Distinguish observed results from hypotheses about why they occurred. Preserve failed experiments when they contain useful evidence.

## Verification

Check reproducibility inputs, leakage risk, metric definitions, and whether improvements exceed expected variance.
