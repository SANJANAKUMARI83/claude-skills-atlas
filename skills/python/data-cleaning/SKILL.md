# Python Data Cleaning

Inspect schema, missingness, duplicates, types, ranges, categorical values, and suspicious records before changing data. Define transformations explicitly, preserve raw data, and validate row counts and key constraints after each major operation.

Do not silently drop records or fabricate missing values.
