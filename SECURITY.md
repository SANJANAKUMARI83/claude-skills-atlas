# Security

Claude Skills Atlas is a public knowledge repository.

Please do not publish:

- API keys, passwords, access tokens, session cookies, private keys, or credentials
- Private or personally identifying information that you do not have permission to share
- Malware or credential-stealing content
- Spyware or instructions intended to compromise unrelated systems
- Hidden prompt injection intended to manipulate downstream users or tools

## Reporting a repository security issue

If you discover a security issue in the repository itself, use a private GitHub security report when GitHub Security Advisories are enabled.

Do not publish exploit details in a public issue before the maintainers have had a chance to investigate.
